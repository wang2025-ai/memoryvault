Three steps. Two minutes.

If you can run a command, your AI can remember your work.

Step 1 — Index

Point it at your notes

Markdown, text, JSON, PDF and HTML. Recursive, incremental, and it keeps working with no internet.

mvault index ~/notes
Step 2 — Serve

Expose it over MCP

One line in your client config. MemoryVault speaks the Model Context Protocol, so any MCP client can use it.

mvault serve
Step 3 — Ask

Ask about your own work

"What did I write about rate limiting?" — the AI searches your vault and cites file and line.

You: what do my notes say about rate limiting?

Built like it matters

The defaults are the product. We obsessed over them so you don't have to.

🔒

Local-first, always

Indexing, vectors and search all run on your machine. Full-text search works with the network cable pulled out.

⚡

Zero-config search

Keyword search (FTS5 trigram + BM25) works out of the box, in English and Chinese. No keys, no accounts.

🧠

Semantic, when you want it

Add Ollama or OpenAI embeddings and queries fuse both layers with Reciprocal Rank Fusion. Provider down? It degrades, never breaks.

🤝

Model-neutral

One vault behind the open MCP standard — use it from Claude, Cursor, ChatGPT or your own tooling. No lock-in.

📦

Your data, portable

Everything lives in one SQLite file. Export it, back it up, delete it. Your memory is not our business model.

👀

Live sync

mvault watch keeps folders in sync as you edit — new notes are searchable seconds after you save them.

Connect your AI

Drop this into Claude Desktop's claude_desktop_config.json or Cursor's .cursor/mcp.json.

{ // Claude Desktop · Cursor · any MCP client "mcpServers": { "memoryvault": { "command": "node", "args": ["/absolute/path/to/memoryvault/bin/mvault.js", "serve"] } } }
